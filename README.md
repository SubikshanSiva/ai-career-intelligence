# AI Career Intelligence

An AI-powered career intelligence platform that analyzes resumes, identifies skill gaps, recommends personalized learning paths, and conducts AI-powered interviews.

## Objective

The goal of this project is to combine Artificial Intelligence, Machine Learning, NLP, RAG, AI Agents, and Full-Stack Development into a practical career assistance platform.

## Planned Technologies

* Python
* Machine Learning
* NLP
* LLMs
* RAG
* Vector Database
* AI Agents
* FastAPI
* React
* MongoDB
* Docker

## Development Challenge

This project is being developed as part of a 30-day AI Engineering learning challenge, with daily technical learning and implementation shared publicly.
